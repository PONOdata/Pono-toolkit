What it does.

Pono Toolkit is a fork, not a rewrite. Most of the surface is upstream Lenovo Legion Toolkit. The items below are the differences this fork adds.

01

Auto-detect Dynamic Lighting

The lighting page surfaces when a LampArray-conformant device is present. No debug flag, no hidden setting.

02

Fn+F8 airplane toggle

Flips the Windows airplane state directly through the registry and a Radio Management Service bounce, then confirms with a notification. If the registry write is refused, it opens Settings instead.

03

Smart-key cycle sync

When an automation pipeline fires from an event (a game launch, for example), the smart-key cycle index advances past that quick action, so the next press produces the next action rather than a stale repeat.

04

System indicator effects

BatteryLow as a red pulse below a threshold, Charging as a gradient sweep on AC, CapsLock as an indicator. A wall-clock sample throttle keeps the cadence steady regardless of animation speed.

05

Hot-path work on the render loop

The render loop runs at 30 Hz with cached capability probes, reused color and index buffers, and once-per-frame transition math. Lower CPU, steadier effects.

06

Isolated AppData

Settings, logs, and integrations live under %LOCALAPPDATA%\PonoToolkit\. An existing Lenovo Legion Toolkit install is untouched and can run side by side.

Where the rest comes from

Power modes, fan curves, hybrid graphics, the keyboard lighting controllers, sensors, and the automation engine are upstream Lenovo Legion Toolkit, gated on Lenovo hardware. On a non-Lenovo laptop those controls do not apply, so they do not appear. The upstream page credits the people whose work that is.
