Install

Run the installer.

Three steps. The installer is signed and runs as administrator. It installs to its own directory and leaves any existing Lenovo Legion Toolkit install alone.

  1. Download PonoToolkitSetup-v0.3.8.exe from the download page, and verify its checksum.
  2. Run as administrator. Inno Setup completes in seconds and writes to C:\Program Files\PonoToolkit\.
  3. Launch from the Start menu. First run shows the upstream credit and a language picker. Choose your locale and you are done.

Coexistence is intentional. Pono Toolkit installs to its own Program Files directory, uses a distinct AppId and mutex, and stores settings under %LOCALAPPDATA%\PonoToolkit\. An existing Lenovo Legion Toolkit install keeps working on the same machine. If you have prior Pono Toolkit settings under the legacy shared path, they migrate forward on first launch.

Why administrator

Pono Toolkit reads and writes system-level hardware settings, so Windows requires administrator rights on install and on launch. If you would rather not grant that, do not install it.
